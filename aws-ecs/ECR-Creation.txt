
# 📘 Amazon ECR Documentation - From Scratch

## ✅ Overview
Amazon Elastic Container Registry (ECR) is a fully managed Docker container registry that makes it easy to store, manage, and deploy container images.

## 📌 Pre-requisites
1. AWS Account
2. AWS CLI installed (v2 preferred)
3. Docker installed and running
4. IAM User with permissions to use ECR (`AmazonEC2ContainerRegistryFullAccess`)
5. Configured AWS CLI with `aws configure`

## 🧱 Steps to Create and Use Amazon ECR

### 🚀 Step 1: Install and Configure AWS CLI
```bash
sudo apt update
sudo apt install awscli -y
aws --version
```

### ⚙️ Configure AWS CLI
```bash
aws configure
```
> Provide:
- AWS Access Key ID  
- AWS Secret Access Key  
- Region (e.g., `us-east-1`)  
- Output format (e.g., `json`)

### 🐳 Step 2: Install Docker (if not already installed)
```bash
sudo apt update
sudo apt install docker.io -y
sudo systemctl start docker
sudo systemctl enable docker
sudo usermod -aG docker $USER
newgrp docker
```

### 🏗️ Step 3: Create ECR Repository
```bash
aws ecr create-repository \
  --repository-name my-ecr-repo \
  --region us-east-1
```

📌 Note the output: You will see the ECR repository URI like:
```
123456789012.dkr.ecr.us-east-1.amazonaws.com/my-ecr-repo
```

### 🔐 Step 4: Authenticate Docker to ECR
```bash
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin 123456789012.dkr.ecr.us-east-1.amazonaws.com
```

### 🏗️ Step 5: Build Your Docker Image
Create a simple Dockerfile:
```dockerfile
FROM python:3.9-slim
WORKDIR /app
COPY . /app
CMD ["python", "-m", "http.server", "8000"]
```
Then build:
```bash
docker build -t my-ecr-image .
```

### 🏷️ Step 6: Tag Your Docker Image
```bash
docker tag my-ecr-image:latest 123456789012.dkr.ecr.us-east-1.amazonaws.com/my-ecr-repo:latest
```

### 📤 Step 7: Push Image to ECR
```bash
docker push 123456789012.dkr.ecr.us-east-1.amazonaws.com/my-ecr-repo:latest
```

### ✅ Step 8: Verify the Image in ECR
```bash
aws ecr list-images --repository-name my-ecr-repo --region us-east-1
```

## 📦 Example Docker Project Structure
```
my-docker-app/
├── Dockerfile
├── index.html
```

## 📘 Useful AWS ECR CLI Commands
- Delete repository:
```bash
aws ecr delete-repository --repository-name my-ecr-repo --force
```

- List repositories:
```bash
aws ecr describe-repositories
```

- Get image details:
```bash
aws ecr describe-images --repository-name my-ecr-repo
```
